## English

A standalone creative mode terrain sculpting tool extracted from the Create Mod.

### Overview

The Handheld Worldshaper is a powerful creative mode tool that allows you to perform large-scale terrain shaping and block placement from a distance.

### Features

- **Multiple Brush Types**: Cuboid, Sphere, Cylinder, Surface, Cluster
- **Flexible Tool Modes**: Fill, Place, Replace, Clear, Overlay, Flatten
- **Various Placement Options**: Merged, Attached, Inserted modes
- **Pattern Filling**: Solid, Checkered, Random fill patterns
- **Undo/Redo**: History management support
- **Long Range Operation**: Up to 128 blocks range

### Usage

1. Find "Creative Worldshaper" in the creative mode inventory
2. **Left Click on Block**: Set fill material
3. **Right Click on Block**: Apply current brush and tool
4. **Shift + Right Click**: Open configuration interface

### Technical Information

- **Minecraft Version**: 1.21.1
- **Mod Loader**: NeoForge 21.1+
- **Development Language**: Java 21

### Building

```bash
./gradlew build
```

Built artifacts are located in the `build/libs/` directory.

## 中文

从机械动力（Create Mod）中分离的独立创造模式地形塑形工具。

### 介绍

手持式世界塑形器是一个强大的创造模式工具，可以让你在远距离进行大面积地形塑造和方块放置。

### 主要特性

- **多种笔刷类型**：矩形体、球体、圆柱体、表面、簇状
- **灵活的工具模式**：填充、放置、替换、清除、覆盖、平整
- **多样的放置选项**：结合、依附、插入模式
- **图案填充**：实心、棋盘格、随机填充等
- **撤销/重做**：支持历史操作管理
- **远距离操作**：最大作用距离 128 格

### 使用方法

1. 在创造模式物品栏中找到"创造模式世界塑形器"
2. **左击方块**：设置填充材料
3. **右击方块**：应用当前笔刷和工具
4. **Shift + 右击**：打开配置界面

### 技术信息

- **Minecraft 版本**：1.21.1
- **Mod Loader**：NeoForge 21.1+
- **开发语言**：Java 21

### 构建

```bash
./gradlew build
```

构建产物位于 `build/libs/` 目录。
